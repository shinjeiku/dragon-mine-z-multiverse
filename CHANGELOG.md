# Changelog

All notable changes to this project will be documented here.

## 0.2.0 - 2026-08-13

- Add Super Saiyan God, Super Saiyan Blue, Super Saiyan Evolved, Ultra Instinct, Ultra Ego, and Mastered Ultra Instinct for Saiyans.
- Add the requested TP prices, mastery prerequisites, stat progression, hair styles, colors, auras, outlines, scale changes, and lightning effects.
- Add per-player low-alignment palettes for Super Saiyan Blue and Super Saiyan Evolved at alignment 40 or lower.
- Add custom divine transformation audio and a seamless charging loop with five-tick fade-in and fade-out behavior.
- Add God Forms and Ultra Forms skill-tree artwork and localization.
- Generate server-editable Dragon Mine Z form configurations without overwriting existing files.

## 0.1.0 - 2026-08-13

- Add the Multiversal Compass.
- Add safe anchored travel to unlocked Dragon Mine Z Space Pod destinations, including datapack-provided destinations.
- Add safe dimension-aware travel to the Nether and The End.
- Respect Dragon Mine Z quest locks and character death state.
- Add configurable travel cooldown and safe-arrival search radius.
- Add the crafting recipe, recipe-book unlock, localization, and creative-tab integration.
